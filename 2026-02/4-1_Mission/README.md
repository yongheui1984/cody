## 시연

Figma 프로토타입: [손끝 화면 흐름 보기](https://www.figma.com/proto/hx4qUDMvZuFD7uGVMgmY1r/4-1?node-id=0-1&t=ajZKLpSu81bbJYbD-1)

`prototype/index.html`을 Chrome 등에서 열거나, `figma/손끝_클릭시안.odp`를 LibreOffice Impress에서 열어 슬라이드 쇼를 시작한다. 두 파일 모두 로컬에서 실행할 수 있다.

1. 메인에서 **모든 클래스 보기**를 눌러 목록을 연다.
2. 목록에서 **물레로 빚는 나만의 그릇**을 눌러 상세를 연다.
3. **예약 내용 확인**에서 일정·인원·가격을 확인하고 **닫기**를 누른다.
4. 왼쪽 위 화살표로 목록과 메인에 돌아간다. 메인의 추천 카드로 상세에 바로 갈 수도 있다.

브라우저판에서는 전체·도예·꽃 공예 필터를 조작할 수 있다. 목록에서 상세로 연결된 수업은 대표 물레 수업 한 개다.

## 사용 도구와 출처

이미지 생성에는 **OpenAI ImageGen(내장 도구)**을 사용했다. **Python Pillow**로 사진을 잘라내고, **HTML/CSS**로 한글과 UI를 조판했다. **Google Chrome**에서 PNG를 내보내고 **Playwright**로 동작을 확인했다. **python-pptx**로 PNG와 클릭 영역을 배치한 뒤 **LibreOffice Impress**용 ODP로 변환하고 화면 간 링크를 검증했다. 타인의 디자인과 사진은 참조하지 않았다.

## 제출 상태

Figma에 PNG 네 장을 배치하고 메인 → 목록 → 상세 → 예약 미리보기 및 뒤로 가기 화면 전환을 연결했다. 프로토타입 링크는 로그인하지 않은 상태에서도 열리는 것을 확인했다. [Figma 화면 연결 캡처](figma/Figma_화면연결.png)에서 네 화면의 연결을 확인할 수 있다.

코랩 세션에서 조원들과 결과물과 작업 과정을 공유하고 비교했으며, 조원 전원이 Figma 프로토타입에 문제없이 접속했다. 세션 내용은 코랩 세션 리포트에 정리했다.
