# 세미나 A 수행 보고서 · AI 기반 UI/UX 디자인 시안 제작

## 이 미션이 요구하는 것

텍스트로 표현한 서비스 아이디어를 이미지 생성 AI로 시각화하고, 생성 결과를 검토하고 수정해 다른 사람이 직접 클릭해 볼 수 있는 시안으로 만드는 과제다. 이미지의 완성도와 함께 프롬프트를 어떻게 수정했는지, 어떤 부분을 사람이 고쳤는지, 화면 전환이 서비스 이용 순서를 얼마나 잘 설명하는지를 보여줘야 한다.

## 서비스와 설계 의도

‘손끝’은 퇴근 후나 주말에 갈 만한 공방을 찾는 사람을 위한 가상 서비스다. 메인은 도예 사진과 추천 카드로 수업에 관심을 갖게 한다. 목록은 같은 위치에 시간·소요 시간·가격을 반복해 비교하기 쉽게 만들었다. 상세는 대표 수업의 일정과 난이도, 1인 가격을 보여주고 예약 내용을 확인할 수 있게 했다. 탐색 중에는 상단 뒤로 버튼이나 하단 탭으로 화면을 오갈 수 있다.

## 작업에서 확인한 점

- **프롬프트의 구조가 화면 구성에 영향을 준다.** 초안의 폭넓은 요청에서는 AI가 검색창과 인기 목록까지 넣었다. 두 번째 프롬프트에서 요소의 순서와 사진 위치를 정하자 한 장의 도예 사진이 중심이 됐다. 색 코드를 명시하고 화면마다 반복하니 결과를 정리할 공통 기준이 생겼다.
- **텍스트 분리 지시는 후가공을 줄이는 데 도움이 된다.** 목록은 글자 자리가 대부분 비어 있었고, 상세에서는 글자를 빼 달라는 지시에도 워드마크와 설명이 생성됐다. 최종에는 사진을 잘라내고 실제 글자로 다시 조판해 모든 화면의 한글과 숫자를 읽을 수 있게 했다.
- **같은 수업은 같은 단서로 알아볼 수 있어야 한다.** 상세의 물레 사진을 목록에도 사용하고, 메인부터 상세까지 수업명과 브랜드 색을 유지했다. 시드를 제공하는 도구에서는 같은 설정으로 변경 전후를 비교할 때 시드를 고정할 수 있다. 기존 시안을 이미지 레퍼런스로 넣으면 다음 화면에 사진 톤과 구성 규칙을 전달할 수 있다. 이번에는 같은 색과 촬영 분위기를 프롬프트로 지정하고 후가공에서 사진과 조판을 통일했다.
- **클릭해 봐야 화면 간 관계가 드러난다.** 메인 → 목록 → 상세 → 예약 미리보기와 반대 방향을 검증했다. 목록은 전체 3개, 도예 2개, 꽃 공예 1개가 보이는지 확인했다. 예약 내용은 가상 데이터로 시연된다.

## 코랩과 제출

코랩 세션에서 조원들과 시안과 작업 과정을 공유하고 Figma 사용법을 함께 익혔다. 조원 전원이 프로토타입에 문제없이 접속했으며, 세션 내용은 코랩 세션 리포트에 기록했다. 제출할 때는 산출물과 Figma 화면 연결 캡처를 GitHub 저장소에 올리고 저장소 URL을 제출한다.
