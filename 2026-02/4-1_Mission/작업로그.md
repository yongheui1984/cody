# 손끝 · 작업 로그

## 기획

손끝은 서울 성수동에서 공예 원데이 클래스를 찾는 가상 모바일 서비스다. 처음 방문한 사람이 추천 수업을 발견하고, 수업 목록에서 시간과 가격을 비교한 뒤, 상세 화면에서 예약에 필요한 정보를 확인하도록 만들었다. 수업명, 공방명, 일정과 가격은 화면을 보여 주기 위해 만든 가상의 정보다.

- 이미지는 **OpenAI ImageGen(내장 도구)**으로 만들었다.
- 이미지를 고칠 때는 Python Pillow, HTML/CSS, Chrome을 사용했다. 수정한 화면을 Chrome에서 캡처해 PNG 이미지로 저장했다.
- 처음 만든 화면은 941 × 1672 픽셀이었다. 마지막에는 432 × 768 크기의 화면을 두 배 크기로 캡처해 이미지마다 864 × 1536 픽셀, 9:16 비율로 맞췄다.
- 다른 사람의 화면 디자인이나 사진은 참고하지 않았다. 사진은 AI로 만든 화면에서 잘라 사용했다.

## 1. 초안 · 메인

```text
Design a high-fidelity mobile UI mockup for a fictional Korean neighborhood craft workshop booking app called 손끝. Show one 9:16 main screen, a header, a featured ceramics class with a photograph, categories, and a bottom tab bar. Use Korean UI text and a calm editorial look with warm ivory and earthy green. Flat, straight-on, full bleed with no device frame.
```

동네 공예 수업 서비스라는 생각을 바탕으로 메인 화면을 만들었다. 생성 결과에는 성수동 검색창, 추천 도예 사진, 여섯 개의 수업 분류, 동네 인기 수업 카드, 다섯 개의 메뉴 버튼이 들어갔다. 따뜻한 실내 사진과 아이보리·녹색 조합에서 서비스의 분위기가 잘 드러났다. 좁은 카드 안의 작은 한글과 숫자는 화면을 줄이면 읽기 어려웠다. 검색·찜·마이페이지도 추가되어 보여 줄 기능이 많아졌다.

## 2. 수정 · 메인

```text
Create one flat, straight-on, 9:16 mobile UI mockup of the home screen for 손끝, a fictional Seoul craft class booking service. Warm paper #F7F3EA, deep pine #18372C, muted rust #A64F37, quiet editorial photography. Match this vertical hierarchy: slim location and wordmark, large two-line intro, one dominant wide photograph of hands shaping a ceramic bowl on a pottery wheel in a softly sidelit Seoul studio, editorial feature card, a pale category CTA strip, bottom navigation. Keep generous margins and editorial rhythm. Use empty clean spaces for all text labels, no invented writing or line placeholders. Only a single screen edge-to-edge, no device, no perspective, no watermark. Maintain a useful wide crop around the ceramics photo.
```

초안의 추천 사진을 중심으로 시선을 모으기 위해 맨 위 제목, 소개, 사진, 추천 카드, 수업 찾기 버튼, 아래쪽 메뉴 순서를 자세히 적었다. 색을 이름과 코드로 함께 정하고, 글자가 들어갈 자리는 비워 달라고 요청했다. 추천 사진이 화면 폭을 사용하고 상단에 넉넉한 공간이 생겼다. 다만 AI가 분류 아이콘과 메뉴 버튼 다섯 개를 계속 넣었고, 추천 카드에 사진을 한 장 더 넣었다. 마지막에는 도예 사진을 사용하고 수업 찾기 버튼과 메뉴 버튼 두 개를 직접 만들었다.

## 3. 최종 생성 · 목록과 상세

목록에서는 세 수업을 같은 크기의 사진과 정보로 비교하도록 했다. 상세 화면에는 같은 도예 수업임을 알아볼 수 있는 사진과 예약에 필요한 정보를 넣었다. 두 화면에 같은 색상, 따뜻한 자연광, 여유 공간을 사용하고 사진과 글자 자리를 나눴다. AI가 이미지를 만들 때 사용하는 시작값인 시드는 고정하지 않았다. 대신 같은 분위기를 반복해서 요청하고 상세 사진을 목록의 같은 수업에도 사용해 화면을 비슷한 느낌으로 맞췄다.

### 목록 프롬프트

```text
Use case: ui-mockup. Make the class LIST screen of 손끝, a fictional mobile craft workshop booking service for Seoul. One full-bleed flat 9:16 portrait screen with a warm ivory paper background #F7F3EA, deep pine green #18372C and muted rust #A64F37. Keep 6% side margins. Top back affordance, blank two-line title space, filter chip row, then three simple stacked editorial list rows. In each row put a large, square, realistic editorial photo on the left and a spacious clean ivory copy area to the right. Show three distinct warm photographs: (1) two unadorned ivory stoneware cups on linen, (2) a person shaping a bowl on a pottery wheel in a warm Korean ceramic studio, (3) hands arranging a small bundle of dried flowers above linen. Keep photos clean and independent, no overlays. Bottom fixed ivory navigation. Leave all UI letters, numbers and price areas blank for manual typesetting; do not add fake type, icons in photos, watermarks or device borders.
```

세로로 쌓인 목록과 비어 있는 설명 공간이 만들어져 사진 옆에 수업명, 일정, 가격을 나란히 배치할 수 있었다. 만들어진 화면에는 요청하지 않은 선택 버튼 다섯 개와 아래쪽 아이콘 다섯 개가 들어갔다. 마지막에는 전체·도예·꽃 공예 선택 버튼 세 개와 메뉴 버튼 두 개를 만들었다. 목록 화면에서 흙컵과 꽃다발 사진을 사용하고, 물레 수업에는 상세 화면의 사진을 다시 사용했다.

### 상세 프롬프트

```text
Use case: ui-mockup. Make the class DETAIL screen of 손끝, a fictional mobile craft workshop booking service for Seoul. One full-bleed flat 9:16 portrait screen with warm ivory paper #F7F3EA, deep pine green #18372C and muted rust #A64F37, 6% inset. Top back affordance and a wide rectangular editorial class photo. Show only the hands of a potter guiding a small beige ceramic bowl on a wheel from an intimate slightly overhead angle; dusty clay, natural warm studio window light from the left, olive-grey linen sleeve, no utensils obstructing the hands. Under the photo leave clean space for a small category label, a two-line title, a single metadata row, and a short description. At the bottom reserve a fixed ivory footer with a dark pine CTA. No real or invented text, numbers, watermarks, device frame, perspective, or text on top of the photograph. Keep photo separate from all interface copy.
```

요청한 대로 손과 물레를 가까이서 찍은 사진과 아래쪽 버튼 공간이 만들어졌다. 글자를 넣지 말라는 요청에도 서비스 이름, 수업명, 위치와 설명, 예약 버튼 문구가 들어갔다. 사진 부분만 잘라 사용하고, 마지막 화면에는 제목과 설명, 일정·시간·난이도와 1인 가격을 직접 입력했다.

## 이미지 수정과 화면 이동

1. 수정 메인의 도예 사진, 최종 목록의 흙컵과 꽃다발 사진, 최종 상세의 물레 사진을 Pillow에서 잘랐다. 처음 만든 화면의 글자나 필요 없는 아이콘과 선이 사진에 들어가지 않도록 잘라내는 범위를 확인했다.
2. HTML로 한글과 가격을 다시 입력했다. 메인에서는 추천 사진과 버튼을 연결하고, 목록에는 같은 크기의 사진과 일정·가격을 세 번 반복해 넣었다. 상세 화면에는 가격과 예약 미리보기 버튼을 함께 넣었다.
3. 아이보리 `#F7F3EA`, 소나무색 `#18372C`, 짙은 적갈색 `#923E29`를 사용했다. 작은 강조 문구에는 이미지를 만들 때 요청한 적갈색 `#A64F37`보다 어두운 값을 사용했다.
4. Chrome에서 메인·목록·상세 PNG를 캡처해 클릭할 수 있는 발표 자료에 넣었다. 메인의 추천 카드와 목록의 물레 수업 카드는 상세로 이어지며, 상단 뒤로 버튼과 하단 탭으로 이전 화면에 갈 수 있다.
5. 보너스로 시안을 HTML/CSS로 만들고 JavaScript로 목록 선택 버튼과 예약 미리보기를 연결했다. Chrome에서 화면 이동, 뒤로 가기, 선택 버튼 세 가지, 예약 창 열기·닫기, 키보드 이동과 320픽셀 화면의 가로 크기를 확인했다.
