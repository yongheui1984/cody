# AI Agent에게 일 제대로 시키는 법 배우기

가상의 시립 도서관 운영 기록을 방문자용 영어 휴실 공지로 바꾸는 과업을 통해 모델 비교와 프롬프트 개선 과정을 정리했다.

1. [모델 비교와 선택](docs/model-comparison.md) — 세 모델의 같은 과업 수행 결과와 선정 근거
2. [시스템 설계](docs/system-design.md) — 페르소나, 프롬프트, 예시, 검증 전략과 개선 이력
3. [실행 로그](docs/run-log.md) — 대화 원문, 사실 확인과 작업 기록
4. [미해결 기록](docs/unresolved.md) — 해결하지 못한 과업과 시도 내용

[보너스 수행 기록](bonus/보너스-수행기록.md)에는 프롬프트 재사용 준비, 이미지 생성 결과와 API 호출 준비 내용을 정리했다.
