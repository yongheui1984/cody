# 2026 영화 티어리스트 웹페이지 기획서

## 1. 누가 쓰나

- 사용자: 유튜버 1명. 방송 중에 시청자들에게 보여 주면서 직접 조작한다.
- 시청자: 방송 화면을 보기만 한다. 투표, 채팅 연동 등 참여 기능은 없다.
- 사용 환경: 유튜버의 맥에서 크롬 창으로 띄워 방송에 보여 준다.
- 실행 방식: 서버 없이 `index.html`을 파일로 바로 열어서 사용한다.
- 작업 폴더: `/Users/mac/Documents/문서 - 김용희/Codyssey/Movie_Tier_List`

## 2. 무엇을 하려고

- 2026년 1월 1일부터 대한민국에서 개봉해, 2026-11-10 기준으로 관객 100만 명 이상을 기록한 영화를 방송에서 티어(S~D)로 나눠 보여 주는 티어리스트 웹페이지를 만든다.
- 영화 목록은 고정이며, 방송마다 바꾸지 않는다.
- 결과는 화면으로 보여 주고, 이미지(PNG)로도 저장할 수 있어야 한다.
- 화면 분위기는 오스카 시상식 같은 느낌으로 하고, 배경은 영화 시상식 실사 사진을 인터넷에서 찾아 넣는다.
- 페이지 제목은 "2026 오스카 시상식" 같은 형식으로 새로 짓는다.

## 3. 화면과 동작

### 화면 구성

- 화면 크기: 크롬 창 크기에 맞춘다. 창이 아주 작거나 세로로 길 때의 화면은 작업 시 정한다.
- 배경: 영화 시상식 실사 사진.
- 상단: 시상식 느낌의 제목 문구.
- 중앙: 티어 표. S등급부터 D등급까지 있으며, 왼쪽 정렬이 아니라 시상식처럼 피라미드 형태로 배치한다.
  - 등급별로 들어갈 영화 수는 피라미드 형태가 되도록 적당히 나눈다.
  - 각 티어의 칸 수를 모두 더하면 영화 편수와 같다.
  - 각 티어에는 그 티어의 칸 수만큼 점선 박스가 있다.
- 하단: 영화 슬라이드. 영화는 포스터 카드(포스터와 제목)로 보인다.
- 버튼 2개: "이미지 저장", "초기화".

### 동작

- 슬라이드는 자동으로 계속 흐르다가, 카드를 드래그로 잡으면 멈춘다. 흐르는 속도와 카드 순서는 작업 시 정한다.
- 슬라이드의 카드를 티어의 점선 박스로 드래그앤드롭해 배치한다.
- 티어에 올린 카드를 다른 티어로 다시 옮길 수 있고, 슬라이드로 되돌릴 수도 있다.
- 티어에 올린 카드에도 포스터와 작은 제목이 함께 보인다.
- 티어 전체 색은 배치된 포스터 수에 따라 바뀐다.

  | 상태 | 색 |
  |---|---|
  | 아무것도 안 올린 상태 | 회색 |
  | 정해진 칸 수보다 적게 올린 상태 | 노랑 |
  | 정해진 칸 수와 정확히 같은 상태 | 초록 |
  | 정해진 칸 수를 넘겨 올린 상태 | 빨강 |

- 새로고침해도 배치 상태가 남는다.
- "초기화"를 누르면 맨 처음 상태로 돌아간다.
- "이미지 저장"을 누르면 배경 사진과 제목을 포함한 티어 표가 16:9 비율의 PNG 이미지로 저장된다. 슬라이드와 버튼은 이미지에 넣지 않는다. 해상도와 파일 이름은 작업 시 정한다.
- 파일로 열어도 이미지 저장이 되도록, 포스터와 배경 이미지는 페이지가 읽는 데이터 파일 안에 내장한다.

## 4. 필요한 자료

- 영화 목록: 2026년 1월 1일부터 대한민국에서 개봉한 영화 중, 2026-11-10 기준 관객 100만 명 이상을 기록한 영화. 작업하는 쪽이 만든다. 관객 수 출처 표기는 필요 없고, 만든 뒤 확인받지 않는다.
- 포스터 이미지: 작업하는 쪽이 직접 검색해 저장한 뒤 페이지에 넣는다.
- 배경 이미지: 영화 시상식 실사 사진. 작업하는 쪽이 인터넷에서 찾아 저장한 뒤 페이지에 넣는다.
- 유튜버가 따로 제공할 자료는 없다.

## 5. 완성 기준

1. `index.html`을 크롬에서 서버 없이 바로 열어 사용할 수 있다.
2. 화면이 크롬 창 크기에 맞춰 보이고, 배경에 영화 시상식 실사 사진이 들어간다.
3. 목록의 모든 영화가 포스터 카드(포스터와 제목)로 슬라이드에 보인다.
4. 슬라이드가 자동으로 계속 흐르고, 카드를 잡으면 멈춘다.
5. S~D 티어가 피라미드 형태이고, 각 티어에 정해진 수만큼 점선 박스가 있으며 전체 칸 수가 영화 편수와 같다.
6. 드래그앤드롭으로 카드를 티어에 배치하고, 다른 티어로 옮기고, 슬라이드로 되돌릴 수 있다.
7. 티어 색이 회색, 노랑, 초록, 빨강 규칙대로 표시된다.
8. 새로고침해도 배치 상태가 남는다.
9. "초기화"를 누르면 맨 처음 상태로 돌아간다.
10. "이미지 저장"을 누르면 배경 사진과 제목을 포함한 티어 표가 16:9 PNG 이미지로 저장된다.

| 16 | 평가포기(똥맛) 티어표를 1 × 3 배치로 바꿔라.<br>· 3칸을 가로 3칸, 세로 1줄(1 × 3)로 한 줄에 나란히 배열한다. 칸 크기는 피라미드 박스의 2배 그대로다.<br>· 피라미드와의 간격(박스 2개 폭), 피라미드 맨 아랫줄(D 티어)의 아래쪽 끝에 맞추는 위치(15번), 한 덩어리로 화면 가운데에 놓는 것은 그대로다. 티어가 가로로 넓어진 만큼 창 크기에 맞춰 칸 크기를 다시 계산한다.<br>· 3칸을 넘겨 올리면 줄이 아래로 늘어나고(한 줄에 3칸) 티어가 빨강이 된다. 창 높이가 모자랄 때만 카드를 줄인다.<br>· 이미지 저장(PNG)에도 같은 배치와 크기로 넣고, 가로가 넓어진 만큼 이미지 안의 칸 크기를 줄여 양옆 여백을 확보한다. | ① 평가포기의 점선 박스 3개가 한 줄에 가로로 나란히 보이고, 박스 크기는 피라미드 박스의 2배다.<br>② 영화 3편을 올리면 한 줄이 모두 채워져 초록이 되고, 4번째를 올리면 아래에 새 줄이 생기고 빨강이 된다.<br>③ 창 크기를 바꿔도 세 덩어리(천상계·피라미드·평가포기)가 겹치거나 화면 밖으로 넘치지 않고 가운데에 있다.<br>④ "이미지 저장"으로 만든 PNG에도 같은 1 × 3 배치로 들어가고, 양옆이 이미지 가장자리에 붙지 않는다. |
