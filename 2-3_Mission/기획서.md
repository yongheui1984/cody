# 금융·재무·은행 자격시험 길잡이

## 대상 사용자

- 은행·증권·보험·회계 분야 취업이나 이직을 준비하는 대학생과 취업준비생
- 자격증으로 경력을 쌓으려는 금융·재무·회계 직장인
- 해외 금융 자격(CFA, FRM, 미국 CPA 등)을 알아보는 대한민국 국적자와 외국 국적자
- 어떤 자격증부터 따야 할지 모르는 금융 입문자

## 사용 목적

- 대한민국과 세계의 유명 금융·재무·은행 자격증, 면허, 시험을 한 곳에서 비교합니다.
- 같은 시험 목록을 세 가지 기준으로 나누어 봅니다: 난이도별, 준비기간별, 응시요건별.
- 사용자가 나이, 국적, 최종학력, 경력, 하루 공부 가능 시간, 총 준비 개월 수를 고르면, 지금 응시할 수 있고 그 기간에 준비할 수 있는 시험을 추천하고 정보를 보여 줍니다.
- 이번 단계는 로컬 테스트입니다. 서버 없이 HTML 파일 하나를 열어 동작하며, 딥리서치 결과 데이터가 화면과 판정에 맞게 쓰이는지 확인하는 용도입니다.

## 화면 구성과 동작

### 화면 구성

위에서 아래로 한 페이지에 배치합니다.

1. **머리말**: 페이지 이름, 한 줄 설명, 정보 기준일(데이터 조사일)
2. **내 조건 입력**: 드롭다운 9개(필수 7개, 선택 2개)와 `추천 보기`, `초기화` 버튼
3. **추천 결과**: 요약 한 줄, 결과 묶음 3개(지금 도전 가능 / 조건부 / 지금은 불가), 정렬 선택
4. **전체 시험 둘러보기**: 탭 3개(난이도별 / 준비기간별 / 응시요건 비교)와 공통 필터(지역, 분야)
5. **비교 보관함**: 비교에 담은 시험(최대 4개)을 항목별로 나란히 보는 표
6. **시험 상세 창**: 한 시험의 모든 정보와 출처
7. **맺음말**: 데이터 출처와 기준일 안내

### 입력 항목 (드롭다운)

| 구분 | 항목 | 선택지 |
|---|---|---|
| 필수 | 만 나이 | 15세 ~ 70세 (1세 단위) |
| 필수 | 국적 | 대한민국, 미국, 중국, 일본, 인도, 영국, 싱가포르, 그 외 국가 |
| 필수 | 최종학력 | 고등학교 졸업 이하 / 대학 재학(최종학년 아님) / 대학 최종학년 재학·졸업예정 / 전문학사 졸업 / 학사 졸업 / 석사 졸업 / 박사 졸업 |
| 필수 | 경력 연수 | 없음 / 1년 미만 / 1년 ~ 10년(1년 단위) / 10년 초과 |
| 필수 | 경력 분야 | 은행·금융 / 증권·자산운용 / 보험 / 회계·세무 / 일반기업 재무·경리 / 금융 외 분야 / 경력 없음 |
| 필수 | 하루 공부 가능 시간 | 0.5 / 1 / 1.5 / 2 / 3 / 4 / 5 / 6 / 8시간 |
| 필수 | 총 준비 기간 | 1 / 2 / 3 / 4 / 6 / 9 / 12 / 18 / 24 / 36개월 |
| 선택 | 영어 수준 | 선택 안 함 / 거의 못함 / 기초 / 업무 가능 / 고급 |
| 선택 | 관심 분야 | 전체 / 은행·여신·외환 / 증권·투자·자산운용 / 보험 / 회계·세무 / 리스크·컴플라이언스 / 재무설계 |

- 필수 7개를 모두 고르기 전에는 `추천 보기`가 눌리지 않습니다.
- 선택 항목을 건너뛰면 그 항목으로는 걸러내지 않습니다.
- `초기화`를 누르면 입력과 결과가 처음 상태로 돌아갑니다.

### 추천 판정 규칙

`추천 보기`를 누르면 모든 시험에 대해 아래 세 가지를 차례로 판정합니다.

**1) 응시자격 판정** (시험의 응시요건 경로 중 하나라도 충족하면 응시 가능)

- 한 경로 안의 조건(나이, 학력, 경력 연수, 경력 분야)은 모두 충족해야 합니다. 경로가 여러 개면 하나만 충족해도 됩니다. 예: "학사 학위 또는 경력 4년"
- 국적 제한이 있는 시험은 선택한 국적이 허용 국가에 없으면 불가입니다.
- 응시 가능한 시험 중 자격 부여에 경력이나 수료 요건이 따로 있고 사용자가 아직 충족하지 못하면 `조건부`입니다. (시험은 볼 수 있으나 자격 등록에는 추가 요건이 필요한 경우)
- 학점 이수, 전공, 기관 추천처럼 입력만으로 판정할 수 없는 조건은 판정에 넣지 않고 카드에 `추가 확인 사항`으로 표시합니다.
- 영어 수준을 고른 경우, 시험이 요구하는 영어 수준보다 낮으면 `조건부`로 내리고 이유를 적습니다.
- 불가일 때는 가장 가까운 경로 기준으로 부족한 항목을 보여 줍니다. 예: "경력 2년 더 필요"

**2) 학습시간 판정**

- 내 가용 시간 = 하루 공부 시간 × 30일 × 총 준비 개월 수
- 시험의 표준 총 학습시간(최소·표준)과 비교합니다.
  - `충분`: 가용 시간이 표준 시간 이상
  - `빠듯`: 가용 시간이 최소 시간 이상, 표준 시간 미만
  - `부족`: 가용 시간이 최소 시간 미만
- 시험 일정상 처음 응시부터 자격 취득까지 걸리는 최단 개월 수가 총 준비 기간보다 길면 `부족`으로 봅니다.
- 시험이 여러 단계이면 "내 가용 시간으로 어느 단계까지 가능한지"를 한 줄로 표시합니다.

**3) 추천 묶음과 순서**

| 묶음 | 조건 |
|---|---|
| 지금 도전 가능 | 응시자격 가능, 학습시간 `충분` 또는 `빠듯` |
| 조건부 | 응시자격 조건부, 또는 응시자격 가능하나 학습시간 `부족` |
| 지금은 불가 | 응시자격 불가 (부족한 항목을 이유로 표시) |

- 기본 정렬(추천순): 묶음 순서 → 관심 분야 일치 우선 → 학습시간 `충분`이 `빠듯`보다 앞 → 난이도 낮은 순
- 정렬 선택으로 `난이도 낮은 순`, `난이도 높은 순`, `준비기간 짧은 순`으로 바꿀 수 있습니다.
- 결과가 하나도 없으면 "조건에 맞는 시험이 없습니다"와 함께 어떤 입력이 가장 큰 걸림돌인지(시간, 학력, 경력 등)를 안내합니다.

### 추천 카드

- 시험 이름, 시행 국가와 주관기관, 난이도 배지(1~5단계)
- 판정 배지: `응시 가능` / `조건부` / `응시 불가`, `충분` / `빠듯` / `부족`
- 필요 학습시간 대비 내 가용 시간 막대
- 판정 이유 한 줄(충족한 항목과 부족한 항목)
- 핵심 정보 세 가지: 응시료, 연 시행 횟수, 평균 합격률
- `상세 보기`와 `비교에 담기` 버튼

### 전체 시험 둘러보기 (탭 3개)

세 탭은 모두 같은 시험 전체를 보여 주며, 입력 여부와 관계없이 동작합니다. 공통 필터(지역: 한국/해외, 분야)가 세 탭에 같이 적용됩니다.

- **난이도별**: 1단계(입문)부터 5단계(최상급)까지 구역으로 나누어 시험 카드를 보여 줍니다.
- **준비기간별**: 표준 총 학습시간에 따라 단기 / 중기 / 장기 / 초장기 구역으로 나눕니다.
- **응시요건 비교**: 시험이 행, 요건이 열인 표입니다. 열은 최소 나이, 학력, 경력, 국적 제한, 시험 언어, 응시료입니다. 열 제목을 누르면 정렬됩니다. 요건이 여러 경로이면 한 칸 안에 경로별로 나누어 적습니다.

### 난이도와 준비기간 분류 기준

**난이도 1~5단계**: 세 기준을 각각 1~5점으로 매기고, 평균을 반올림해 단계를 정합니다. 합격률이 공개되지 않은 시험은 합격률 기준을 빼고 나머지 둘의 평균을 씁니다.

| 점수 | ① 평균 합격률 | ② 표준 총 학습시간 | ③ 시험 구조 |
|---|---|---|---|
| 1 | 70% 이상 | 60시간 이하 | 아래 가산점 합계 1점 |
| 2 | 50 ~ 69% | 61 ~ 150시간 | 합계 2점 |
| 3 | 30 ~ 49% | 151 ~ 400시간 | 합계 3점 |
| 4 | 15 ~ 29% | 401 ~ 1,000시간 | 합계 4점 |
| 5 | 15% 미만 | 1,000시간 초과 | 합계 5점 |

시험 구조 점수는 기본 1점에 아래 해당 항목마다 1점을 더하며 최대 5점입니다.

- 응시 과목이 3개 이상
- 주관식, 서술형, 계산형 문제 포함
- 3단계 이상의 연속 시험
- 구술, 실습, 법정 수습 같은 비필기 평가 포함

난이도 단계 이름: 1 입문, 2 초급, 3 중급, 4 고급, 5 최상급

**준비기간 구역**: 표준 총 학습시간 기준입니다. 괄호는 하루 2시간, 한 달 30일로 공부할 때의 대략적인 기간입니다.

| 구역 | 표준 총 학습시간 |
|---|---|
| 단기 | 150시간 이하 (약 2.5개월 이하) |
| 중기 | 151 ~ 400시간 (약 6.5개월 이하) |
| 장기 | 401 ~ 1,000시간 (약 16.5개월 이하) |
| 초장기 | 1,000시간 초과 |

### 비교 보관함과 상세 창

- 카드나 표의 `비교에 담기`로 시험을 최대 4개까지 담습니다. 5개째를 담으려 하면 "최대 4개까지 비교할 수 있습니다"를 알립니다.
- 보관함 표는 응시요건 경로, 자격 부여 요건, 시험 구조, 합격률, 학습시간, 응시료, 일정, 난이도 근거를 항목별로 나란히 보여 줍니다.
- 상세 창은 시험 한 개의 모든 항목, 값별 출처 링크, 정보 기준일을 보여 줍니다. 닫기 버튼과 바깥 영역 클릭, `Esc`로 닫습니다.
- 자료에 값이 없는 항목은 빈칸이나 `undefined` 대신 "정보 없음"으로 표시합니다.

- 딥리서치 결과를 HTML 안에 자바스크립트 데이터(`const EXAMS = [...]`)로 넣습니다. 별도 파일을 불러오지 않습니다.
- 조사 대상, 항목, 열거값, 작성 규칙은 `/Users/mac/Documents/문서 - 김용희/Codyssey/Exam_webpage/research_template.md` 에 정리합니다.
- 조사 범위
  - 대한민국: 은행·금융 일반, 금융투자, 보험, 회계·세무, 재무설계, 채용시험
  - 해외: 투자·리스크, 회계·감사, 재무설계, 컴플라이언스, 미국·영국·일본·중국·인도·싱가포르 등 주요국의 금융 면허·자격
  - 우선순위 1순위 시험을 먼저 끝내고, 2순위를 이어서 조사합니다.
  - 지역마다 규정이 다른 시험(미국 CPA의 주별 요건 등)은 대표 기준 하나만 싣고, 나머지는 추가 확인 사항에 적습니다.

  - 기본: 이름, 영문명, 주관기관, 시행 국가, 유형(자격증, 면허, 채용시험), 분야, 한 줄 소개, 취득 후 할 수 있는 일, 공식 사이트
  - 응시요건: 국적 제한, 경로별 조건(나이, 학력, 경력 연수, 경력 분야), 입력으로 판정할 수 없는 추가 확인 사항, 시험 언어, 필요 영어 수준, 시행 국가
  - 자격 부여: 시험 합격 뒤 필요한 경력과 요건, 유효기간, 갱신
  - 시험 구조: 단계, 과목, 문항 형식, 시간, 합격 기준, 연도별 합격률, 연 시행 횟수, 최근 일정
  - 학습: 단계별·전체 최소/표준/최대 학습시간과 근거, 일정상 최단 개월 수
  - 비용: 응시료, 등록·연회비
  - 난이도: 세 기준 점수와 단계, 근거
  - 출처: 값 묶음별 출처 주소와 확인일, 신뢰도, 정보 기준일

### 화면 문구와 기준표

- 입력 선택지 표, 난이도·준비기간 분류 기준표(위 내용)
- 학력, 경력 분야, 분야의 고정 용어 목록(딥리서치 양식의 열거값과 같은 이름을 씁니다)
- 판정 이유와 안내에 쓰는 한국어 문구

## 완료 기준

- 인터넷 연결, 서버, 로그인, 다른 파일 없이 HTML 파일 하나를 더블클릭해서 열립니다. 외부 글꼴, 외부 스크립트, 외부 이미지를 쓰지 않습니다.
- 필수 드롭다운 7개 중 하나라도 비어 있으면 `추천 보기`가 눌리지 않고, 7개를 모두 고르면 눌립니다.
- 필수 7개를 고르고 `추천 보기`를 누르면, 데이터의 모든 시험이 세 묶음(지금 도전 가능 / 조건부 / 지금은 불가) 중 정확히 한 곳에 들어갑니다. 세 묶음의 시험 수를 합하면 전체 시험 수와 같습니다.
- 하루 1시간, 3개월을 고르면 가용 시간이 90시간으로 계산되어 표시되고, 최소 학습시간이 90시간을 넘는 시험은 `부족`으로 표시됩니다.
- 만 17세, 고등학교 졸업 이하, 경력 없음을 고르면 최소 나이나 학력 요건이 있는 시험은 `응시 불가` 묶음에 부족한 항목과 함께 나타납니다.
- 나이가 시험의 최소 나이와 같으면 응시 가능, 1세 적으면 응시 불가입니다. 경력도 요구 연수와 같으면 충족, 1년 적으면 부족입니다.
- 경로가 둘 이상인 시험(예: 학사 학위 또는 경력 4년)은 한 경로만 충족해도 응시 가능으로 나옵니다.
- 난이도별 탭의 시험 수 합계와 준비기간별 탭의 시험 수 합계가 각각 전체 시험 수와 같습니다. 한 시험은 한 구역에만 나옵니다.
- 같은 시험의 난이도, 학습시간, 응시요건이 추천 카드, 둘러보기 탭, 비교 보관함, 상세 창에서 모두 같은 값으로 나옵니다.
- 비교 보관함에는 최대 4개까지 담기고, 담은 시험의 값이 항목별로 나란히 나옵니다.
- 상세 창에 모든 값의 출처와 정보 기준일이 보입니다.
- 화면 어디에도 `undefined`, `null`, `NaN`이 나오지 않고, 값이 없는 항목은 "정보 없음"으로 보입니다.
- 브라우저 개발자 도구 콘솔에 오류가 없습니다.
- 화면 폭 360px에서 응시요건 비교 표를 제외하고 가로 스크롤 없이 읽히고, 모든 버튼과 드롭다운을 누를 수 있습니다.

## 필수 기능

이 페이지의 목적(조건에 맞는 시험 추천과 시험 비교)을 이루는 데 필요한 기능입니다.

- 내 조건 입력(필수 7개, 선택 2개)과 초기화
- 응시자격 판정, 학습시간 판정, 세 묶음 추천 결과와 정렬
- 전체 시험 둘러보기 3개 탭(난이도별, 준비기간별, 응시요건 비교)과 공통 필터
- 비교 보관함(최대 4개)
- 시험 상세 창(값별 출처와 정보 기준일)

## 추가 기능

이번 구현에는 넣지 않고, 이후 구현할 기능입니다.

- 보유 자격증 입력: 이미 딴 자격으로 면제되는 과목이나 선수 자격을 반영한 추천
- 취득 순서 로드맵: 목표 직무에 맞는 자격증 취득 순서 제안
- 시험 일정표: 접수 기간과 시험일, 남은 일수 표시
- "총 준비 기간을 N개월 늘리면 추가로 가능한 시험" 안내
- 전공, 학점 이수 같은 세부 요건을 입력해 추가 확인 사항까지 판정
- 결과 인쇄와 PDF 저장
- 서버 배포와 데이터 정기 갱신

## 한계 및 비목표

1. 데이터는 정보 기준일 시점의 조사 결과입니다. 제도, 응시료, 일정 변경은 반영하지 않으며, 화면에 기준일과 출처를 함께 보여 줍니다.
2. 합격 가능성을 예측하지 않습니다. 학습시간 판정은 가용 시간(하루 시간 × 30일 × 개월 수)과 표준 학습시간의 단순 비교이며, 전공 지식, 학습 효율, 휴식일은 반영하지 않습니다.
3. 서버, 로그인, 데이터베이스, 결제, 시험 접수 연동, 실시간 데이터 갱신은 구현하지 않습니다. 입력값은 저장하거나 외부로 보내지 않습니다.

## 검증 방법

- 시험 중 무작위 10개를 골라, 화면 상세 창에 표시된 응시요건, 응시료, 시험 구조, 합격률을 해당 시험 주관기관의 공식 사이트에 적힌 값과 한 항목씩 대조합니다.
  1. 전체 시험 번호 중 10개를 무작위로 뽑습니다.
  2. 각 시험의 상세 창에서 출처 링크로 공식 사이트를 엽니다.
  3. 네 항목을 화면 값과 공식 사이트 값으로 나란히 적어 같은지 확인합니다.
  4. 다른 값이 나오면 데이터를 고치고 그 시험을 다시 대조합니다. 10개 시험의 네 항목이 모두 같으면 통과입니다.
