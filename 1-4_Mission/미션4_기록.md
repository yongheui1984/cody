# 미션 4 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: Claude Sonnet 5.5 (Claude Code) / 1-4_claude-채팅.png
- 더한 기능과 고른 이유:
  - 고른 이유: 시상식 무대 같은 모양의 완성된 티어리스트 화면(아래 '참고로 받은 화면'에 내용을 풀어 적음)을 보여 주고, 그 기능과 디자인을 `영화_원본.html` 위에 똑같이 더하되 기준은 `기획서.md`에 맞추라고 했다. 원본의 기능(선택 후 등급 글자 누르기, 끌어 놓기, 제목 추가, 자동 저장, 처음으로)은 바꾸지 않았다.
  - 화면과 디자인: 어두운 무대 배경(소리 없이 반복 재생되는 영상)과 금색 포인트, 피라미드 모양 티어(S 1칸·A 2칸·B 3칸·C 4칸), 줄마다 '담긴 수 / 정원'과 상태 색(비면 회색·모자라면 노랑·같으면 초록·넘치면 빨강), 등급별 색 그라데이션과 빛나는 연출.
  - 새 티어: 왼쪽 위 '천상계'(1칸, 카드 3배), 오른쪽 아래 '평가포기 (똥맛 영화)'(3칸, 카드 2배, 💩).
  - 동작: 다른 티어로 옮길 때마다 3초 효과(천상계 구름·S 폭죽·A 색종이·B 물결·C 비·평가포기 💩), 카드를 끌면 따라다니는 복사본과 놓을 칸 강조, 칸 안은 항상 왼쪽부터 채움, 아래 띠에서 안 정한 영화가 흘러감, 선택 후 S·A·B·C 키로 옮기기, 이미지 저장(1920×1080 PNG).
  - 새 아이디어: 오른쪽 '추천 영화' 패널(19편, 포스터·제목·개봉일·'추가' 버튼). 추가하면 '아직 안 정한 영화'로 들어가고 추천 목록에서 빠지며, '처음으로'를 누르면 다시 나온다. 처음 8편과 추천 19편은 실제 포스터를 쓴다.
  - 기획서에 맞추려고 참고 화면과 다르게 한 것: 외부 영상 파일 참조를 없애고 영상·포스터·배경 이미지를 HTML 안에 넣음, 영화 목록을 기획서의 8편으로 함, 좁은 화면에서는 천상계·피라미드·평가포기를 위아래로 쌓고 추천 패널을 맨 아래로 내림.
  - `기획서.md` 맨 끝에 새 기능의 설명과 완성 기준을 덧붙였다.
- 참고로 받은 화면에 들어 있던 내용 (직접 열어 보고 코드를 읽어 정리):
  - 제목은 '2026 골든 티어 어워즈', 머리말에 'THE GOLDEN TIER AWARDS'와 별 세 개. 어두운 무대 배경 위에 금색 글씨.
  - 배경은 별도 영상 파일(`awards_stage.mp4`)을 열 때마다 따로 불러와 반복 재생함.
  - 영화는 2026년에 개봉해 관객 100만을 넘긴 19편이고, 카드마다 실제 포스터 이미지가 HTML 안에 들어 있음.
  - 티어는 일곱 개: 왼쪽에 천상계(1칸), 가운데 피라미드로 S(1칸)·A(2칸)·B(3칸)·C(4칸)·D(5칸), 오른쪽에 평가포기(3칸). 천상계 카드는 일반의 3배, 평가포기 카드는 2배.
  - 줄마다 '담긴 수 / 정원'을 보여 주고 상태에 따라 줄 색이 바뀜. 칸 안 카드는 왼쪽부터 채워지고 정원을 넘기면 줄이 늘어남.
  - 등급마다 다른 색 그라데이션이고, 천상계·S·A·B는 테두리가 빛남. 천상계·S는 글자 칸이 반짝이고 별이 깜빡이며 빛이 줄 위를 쓸고 지나감.
  - 다른 티어로 옮길 때 3초 효과가 나옴: 천상계 구름, S 폭죽, A 색종이, B 물결, C 비, D 천둥·번개, 평가포기 💩.
  - 카드를 끌면 복사본이 따라다니고 놓을 칸이 강조되며, 칸 위에 놓으면 그 자리에 끼워짐. 티어 밖으로 놓으면 안 정한 영화로 돌아감. 카드를 눌러 선택한 뒤 티어 글자나 S·A·B·C·D 키로도 옮김.
  - 화면 아래 띠에서 아직 안 정한 영화가 흘러가고 '남은 영화 ○편'을 보여 줌. 모두 배치하면 '모든 영화를 배치했어요'가 나옴.
  - 버튼은 두 개: '이미지 저장'(16:9 PNG)과 '초기화'(모든 배치를 지움). 등급 배치는 브라우저에 저장함.
  - 없는 것: 영화 제목을 입력해 추가하는 칸, 영화 목록을 바꾸는 방법.
  - 가로로 천상계·피라미드·평가포기를 나란히 놓는 배치라 폭이 약 20칸으로 고정되어 있음.
